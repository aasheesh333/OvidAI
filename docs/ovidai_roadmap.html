02 — The Core Strategy
Free AI for Everyone.
Keys for Power Users.
The single biggest growth unlock: a new user opens the app and gets a working AI reply in under 10 seconds — no API key, no credit card. We become the "Ovid Provider" — our own free model gateway, exactly like OpenCode ships free models.

The Three-Layer Model Strategy

🎁 Ovid Free DEFAULT
Our own gateway proxies genuinely free models — Gemini 2.5 Flash (AI Studio free tier), Groq Llama, Cerebras, GitHub Models, OpenRouter free variants.

Per-user daily quota (e.g. 50 msgs/day) enforced by Firebase Auth UID. No key ever needed.
🔑 BYOK POWER
The 15 providers already in the UI. User pastes their own key → unlimited usage, zero cost to us. Keys stay on-device (flutter_secure_storage).

This is our margin protector — heavy users self-fund.
⭐ Ovid Pro ₹/$ MRR
Phase 4+: pooled premium models (GPT-5, Claude, Gemini Pro) with generous limits, priority queue, image gen, longer memory.

$5–8/mo via Play Billing — only pitched after the habit forms.

The Privacy-First Auth Promise (Our Differentiator)

✓ What syncs to cloud — chat history only
  • Chat sessions + messages → Firestore, per-user, encrypted at rest
  • Session titles & model choice → seamless multi-device resume
  • Free-tier quota counter → per-UID daily allowance
✗ What NEVER leaves the device
  • API keys (BYOK) — secure enclave / EncryptedSharedPrefs only
  • Code, files, repos — Studio syncs via user's own GitHub, not us
  • Browser sessions/cookies — on-device WebView only
The sign-in ask is tiny, the value is huge: "Sign in with Google to save your chats & unlock free AI models." One tap (Firebase Auth Google Sign-In), no password, no card. Code history is explicitly excluded — a trust signal developers will love and share.

Why Upstream Stays Free For Us

  • Gemini AI Studio free tier — generous RPD per key; pool N keys behind the gateway, rotate on 429
  • Groq / Cerebras free tiers — high-RPS LPU inference costs them little, costs us nothing
  • GitHub Models — free with GitHub token; OAuth'd users bring quota with them
  • OpenRouter :free variants — DeepSeek/Llama free endpoints as final fallback
  • Cache aggressively — identical FAQ-style prompts served from Firestore cache, zero inference cost
Cost math at 1M MAU: ~92% of requests hit free upstreams or cache → blended inference cost ≈ < $0.001/user/mo, covered by Pro subscriptions 100× over.

Top Risks & Our Mitigations

⚠ Upstream free tiers shrink
Multi-upstream router + Remote Config model catalog = swap providers with zero app update. On-device Gemini Nano as permanent fallback.
⚠ Quota abuse / bot farms
Firebase App Check (free) attests real devices; per-UID + per-IP limits; anonymous accounts get half quota, nudging sign-in.
⚠ Gateway becomes a cost center
Aggressive semantic cache, prompt-length caps on free tier, and BYOK upsell nudges for heavy users ("add your key → unlimited").
⚠ Trust: "you see my chats"
Public privacy contract: keys & code never leave device (verifiable — open-source the client). Chat sync is opt-out-able, deletable, exportable.
⚠ Play policy on AI apps
Content filters at gateway layer, report/block flows, clear AI-generated labeling — compliant from day one.
The one-line strategy: Google runs our backend for free, users' own devices run our agents for free, upstream labs subsidize our models for free — and we charge only the 3% who want the very best.
