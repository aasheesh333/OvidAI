# P3 Account Implementation Plan

**Goal:** Real Firebase profile presentation and a server-owned, cancellable
24-hour account deletion lifecycle.

**Architecture:** Isolated `server/account` FastAPI routes, PostgreSQL durable
state/UID serialization, Firebase Admin identity/fencing, a supervised expiry
worker, and explicit gateway data cleanup adapters. Flutter consumes confirmed
server state; no app timer or local erase represents server deletion.

**Spec:** Approved design in the task conversation, 2026-10-03.

## Constraints
- Work only in `/tmp/opencode/wt-account`, branch `wip/account`.
- No live deployment/deletion, credential output, commits, or pushes.
- Google and existing email/password only; activation must be reported honestly.
- Keep quota integration behind isolated account hooks.
- Flutter tests use `/root/flutter/bin/flutter test --concurrency=2`.
